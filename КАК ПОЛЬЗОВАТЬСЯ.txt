САЙТ — КАК ПОЛЬЗОВАТЬСЯ
=======================

Посмотреть сайт у себя: открой index.html двойным кликом.

СТРУКТУРА
  index.html, main.js, style.css — сам сайт (трогать не нужно)
  items.js      — ВСЁ содержимое: название сайта и список публикаций
  add.html      — генератор новой публикации (заполнил форму → скопировал блок → вставил в items.js)
  downloads/    — файлы для скачивания (exe, zip и т.д.)
  img/<id>/     — иконки и скриншоты каждой публикации

ДОБАВИТЬ НОВУЮ ПРОГРАММУ / СБОРКУ / КОНФИГ
  1. Открой add.html, заполни поля.
  2. Файл положи в downloads/, картинки — в img/<id>/.
  3. Нажми «Скопировать блок» и вставь его в items.js
     перед строкой «// ↓ следующая публикация — сюда».
  4. Открой index.html и проверь.

ОБНОВИТЬ ПРОГРАММУ
  Замени файл в downloads/, в items.js поменяй version, date, size
  и добавь строку в changelog.

ПОМЕНЯТЬ НАЗВАНИЕ САЙТА / ДОБАВИТЬ ССЫЛКУ НА TELEGRAM
  В начале items.js — блок window.SITE.

ВАЖНО
  На публичных скриншотах не должно быть личного: имени компьютера,
  пути C:\Users\<имя>, IP/MAC-адресов, переписок.

ВЫЛОЖИТЬ В ИНТЕРНЕТ БЕСПЛАТНО (GitHub Pages)
  1. Зарегистрируйся на github.com.
  2. Создай репозиторий (New repository), например «soft», сделай его Public.
  3. «uploading an existing file» → перетащи ВСЁ содержимое этой папки → Commit.
  4. Settings → Pages → Branch: main, папка / (root) → Save.
  5. Через 1–2 минуты сайт будет по адресу https://<твой-логин>.github.io/soft/
  Обновлять — так же: загрузить изменённые файлы в репозиторий.
  Ограничение GitHub: один файл до 100 МБ (большие сборки — на Google Диск и поле link).
